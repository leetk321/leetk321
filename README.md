# 소개 👋

교육 현장에서 필요한 도구와 정보를 쉽게 이용할 수 있는 웹 서비스를 만듭니다.

학생의 계정 정보와 수업 자료를 관리하는 도구, 행사 안내 사이트, 커뮤니티 링크 페이지를 개발하고 있습니다.

## 관심 분야

- 🏫 **교육을 위한 도구** — 학생과 교사가 수업에 집중할 수 있도록 돕는 서비스
- 🌐 **웹 개발** — 필요한 정보와 기능을 이해하기 쉽게 구성하는 웹사이트
- 🔄 **데이터 연동** — Python과 Google Sheets를 활용한 데이터 관리
- 📚 **컴퓨터 과학 기초** — C 언어, 포인터, 자료구조
